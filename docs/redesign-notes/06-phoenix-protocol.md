# Phoenix Protocol means rebuilding RLCoach around a central daily mission core, not polishing dashboards.

- Treat Phoenix Protocol as the standing design memory for future loops: break the UI down to barebones, then rebuild from the question "what does the player need to do next?"
- Primary screen model: one arena-style mission core, one giant next action, supporting telemetry at the edges, and the daily loop shown as Train -> Check -> Tune.
- Visual direction: dark Rocket League arena, cyan energy, perspective grid, luminous circular progress, boost-meter accents, fewer stronger panels, and deliberate motion.
- Every surface must avoid default dashboard/bento-card feel unless the content truly needs a grid.
- Motion standard: ring draw, scan sweep, button boost pulse, panel rise, and short reward flashes; always respect `prefers-reduced-motion`.
- This note supersedes M3 as the creative north star; M3 remains the last committed stable rollout.
